# Issue tracker

This repo tracks agent tasks on a local nawaban board.

- Board: `.nawaban/nawaban.db` in the main checkout (gitignored, one board shared by every worktree).
- CLI: `python3 ~/.nawaban/plugin/nawaban/cli.py --db <absolute path to .nawaban/nawaban.db> <verb>`.
- Usage rules: the `nawaban` skill.
